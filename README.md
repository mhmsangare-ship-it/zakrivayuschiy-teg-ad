# Закрывающий тег

Проектная работа Яндекс Практикума — финальный проект модулей вёрстки.
Страница-рефлексия о пройденном пути обучения.

## Технологии

- семантичная HTML-разметка, БЭМ;
- вариативный шрифт Inter (`font-variation-settings`) и акцентный PressStart2P;
- фиксированный фон из нескольких градиентов;
- резиновая вёрстка через `clamp()` и адаптив под 375px;
- CSS-фильтры, `mix-blend-mode`, `text-stroke` с проверкой через `@supports`;
- модальное окно на элементе `dialog` с `::backdrop`;
- анимация иконки сердца через `transition` и `@keyframes`.
